# CropStack: start here

Self-hosted garden and homestead app (FastAPI + SQLModel/SQLite backend, React PWA frontend, YAML catalog under `catalog/`).

1. Read `docs/ACTIVE_CONTEXT.md` first (state, how to work, next steps), then `docs/PLAN.md` ("Next up"), `docs/LESSONS_LEARNED.md`, `docs/TOOLING_AND_MCP.md`.
2. Keep the living docs current on every release: README, WIKI, CHANGELOG, ARCHITECTURE, PLAN, ACTIVE_CONTEXT, LESSONS_LEARNED (see ACTIVE_CONTEXT "Release checklist").
3. Owner rules: no presets (fully dynamic), never destroy or restrict the owner's work (suggest, don't block), information-first but few key points, professional look, English and metric are enough.
